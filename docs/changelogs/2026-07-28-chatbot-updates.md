## Multi-Model AI Fallback System
- Replaced the single-provider OpenRouter setup with a highly resilient **5-layer AI provider chain** in `src/lib/ai/provider.ts` (`groq-with-nvidia-fallback`).
- The fallback chain executes sequentially upon failure:
  1. **Groq**: `llama-3.3-70b-versatile` (Primary)
  2. **NVIDIA NIM**: `meta/llama-3.1-70b-instruct` (Heavy fallback)
  3. **NVIDIA NIM**: `meta/llama-3.1-8b-instruct` (Fast fallback)
  4. **NVIDIA NIM**: `nvidia/nemotron-mini-4b-instruct` (Lightweight fallback)
  5. **Groq**: `deepseek-r1-distill-llama-70b` (Reasoning fallback)

## Bug Fixes & Security
- **NVIDIA 500 Error Fix**: Removed `additionalProperties: false` from the Zod JSON schemas in `src/lib/ai/tools.ts` because NVIDIA's Python backend was strict and crashed when `.get()` was called on a boolean.
- **Credentials Security**: Stored `GROQ_API_KEY` and `NVIDIA_API_KEY` securely in `.env.local`. Verified that `.gitignore` correctly ignores `.env.local` to ensure credentials are never exposed or committed to the repository. 
- **Groq Email Regex Schema Fix**: Groq's strict JSON Schema validator rejected the `pattern` regex generated by Zod's `.email()` validator in the `schedule_lead_call` and `submit_consultation` tool schemas. Removed `.email()` from schema definitions in `src/lib/ai/tools.ts` and `src/lib/proposal.ts` (which feeds `ConsultationInput`). Runtime email validation is preserved inside each tool's `run()` function. Error was: `invalid JSON schema for tool schedule_lead_call ... '/properties/email/pattern' ... is not valid 'regex'`.
- Updated `GROQ_API_KEY` to a new working key provided by the founder.

## Logo Pixelation Fix
- **Root cause**: The header uses `backdrop-blur-md` which creates a GPU compositing layer. The browser rasterizes the SVG logo into this blurred layer. On scroll-down + scroll-back-up, the browser re-composites at a lower resolution, making the logo appear pixelated/blurry.
- **Fix**: Added `isolation: 'isolate'` and `willChange: 'transform'` to the logo's `<Link>` wrapper in `src/components/Nav.tsx` (line 509). This forces the logo into its own compositing layer, preventing the backdrop-blur from rasterizing the SVG.
